# Shader 输入图探针组

这组图不用于模拟真实用户素材，而用于让不同类型的 shader 都有机会显露其核心变化。渲染测试应保留每张图对应的输出视频，再按“效果是否可见、作用区域是否正确、是否因素材过复杂而难以判断”进行审查。

| 文件 | 主要覆盖的 shader 特征 |
| --- | --- |
| `probe_00_portrait_clean.png` | 人脸/主体轮廓、翻转、中心缩放、肤色、RGB 分离、柔化模糊 |
| `probe_01_landscape_perspective.png` | 全局形变、透视、拉伸、翻转、边缘和局部色彩变化 |
| `probe_02_gray_ramp.png` | 亮度、对比度、曝光、暗角、灰阶色偏 |
| `probe_03_rg_split.png` | RGB 通道偏移、色彩分离、通道混合 |
| `probe_04_ring_mask.png` | 中心/径向 mask、局部光环、圆形区域效果 |
| `probe_05_color_gradient.png` | 色相、饱和度、综合色调和渐变过渡 |
| `probe_06_cross_lines.png` | 横纵线条、扫描线、网格、拉伸与位移方向 |
| `probe_07_edges_corners.png` | 边缘、角点、镜像、裁切、局部轮廓形变 |
| `probe_08_directional_texture.png` | 单一方向纹理、运动模糊、方向性采样、倾斜/旋转结构 |
| `probe_09_local_mask.png` | 多个局部区域、软硬 mask、局部色彩和局部形变 |
| `probe_10_composite_gradient_geometry.png` | 综合色相与亮度渐变、中心圆环、硬边/角点、色块、网格和局部区域；用于一次性暴露颜色、亮度、裁切、旋转、缩放与空间位移 |
| `probe_11_portrait_asymmetric_blocks.png` | 中央人像与四周非对称高饱和色块、黑白块、圆环和硬边；用于同时检查主体类效果、翻转/旋转/缩放、裁切和颜色/通道变化 |

## 建议筛选流程

1. 先为每个库侧 shader 渲染全部探针图。
2. 过滤掉几乎无可见变化、黑场/失真、或只因图像语义复杂而难以判断的结果。
3. 按特效类别保留最能展示其核心变化的 1--3 张图，而不是强行选择一张全局最佳图。
4. 对未知 target，可先用人像、风景和结构图各渲染一轮；再选择最能暴露 target 核心特征的输入图进入后续迭代。

筛选目标是覆盖互补，而不是使单图评分最高：真实主体、透视场景、低频色调、边缘/角点、方向纹理和局部区域应至少各有一个代表。
